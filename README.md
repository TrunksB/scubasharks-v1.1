# Scuba Sharks Uganda Website

A responsive, multi-page static website for **Scuba Sharks Uganda — Professional Divers at Depth.**

## Pages
- `index.html` — Home
- `services.html` — Services
- `about.html` — About Us
- `contact.html` — Contact Us

## How to publish on GitHub Pages
1. Create a new GitHub repository, for example `scuba-sharks-uganda`.
2. Upload all files and folders from this project to the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. GitHub will provide the website address.

## Adding your photos
The website intentionally contains photo placeholders. Add your images inside `assets/`, then update the relevant CSS background or placeholder elements.

The homepage hero expects:
`assets/hero.jpg`

You can also replace the visible `PHOTO SLOT` blocks with `<img>` elements when you have your preferred photographs.

## Notes
- The contact form uses `mailto:` so it works without a backend. It opens the visitor's email application.
- The site is plain HTML/CSS/JavaScript, so it is suitable for GitHub Pages.
- Update the copyright year, wording, training/certification details, and service coverage as your business grows.
